代码模块复用系统 - 使用帮助
系统目的

通过代码模块复用最大化节省Token消耗，提高开发效率。

模块类型说明
  • 核心 - 系统核心功能模块
  • API - API接口相关模块
  • 脚本 - 自动化脚本模块
  • 工具 - 工具函数模块
  • 集成 - 第三方集成模块
  • 测试 - 测试相关模块
主要功能
  1. 扫描模块：自动扫描项目中的可复用代码模块
  2. 查看详情：点击模块名称查看详细信息
  3. 记录使用：记录模块的每次使用，统计节省的Token
  4. 搜索过滤：按名称、类型搜索模块
节省Token计算

每次复用模块时记录节省的Token数，系统会自动统计：

  • 总节省Token数
  • 平均每次复用节省Token数
  • 模块复用效率排名
最佳实践
  • 定期扫描新模块
  • 每次复用后及时记录
  • 优先使用高复用效率的模块
  • 创建通用的工具模块
