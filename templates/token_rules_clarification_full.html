规则歧义说明

用户提供的规则文字存在逻辑重叠，需要明确计算方式。请选择以下解释方式之一：

用户原始规则

- 日消耗 > 10M tokens: -10分
- 日消耗 5-10M tokens: -5分
- 日消耗 2-5M tokens: -3分
- 日消耗 1-2M tokens: -2分
- 日消耗 0.8-1M tokens: -1分
- 日消耗 小于0.8M tokens: -0分
- 日消耗 小于0.5M tokens: +1分
- 日消耗 < 0.1M tokens: +3分
- 日消耗 < 0.05M tokens: +5分
- 日消耗 小于0.01M tokens：+10分

问题：规则有重叠，例如0.03M tokens同时满足"小于0.8M"、"小于0.5M"、"<0.1M"、"<0.05M"、"小于0.01M"

请选择规则解释方式

选项1：互斥区间（当前实现）

解释：每个条件独立，消耗量落在哪个区间就按哪个区间计分。

计算方式：0.03M tokens → 落在"<0.05M"区间 → +5分

区间划分：>10M, 5-10M, 2-5M, 1-2M, 0.8-1M, 0.5-0.8M, 0.1-0.5M, 0.05-0.1M, 0.01-0.05M, <0.01M

选项2：最高奖励原则

解释：满足多个条件时，取最高奖励分数。

计算方式：0.03M tokens → 满足"<0.05M"(+5)和"<0.01M"(+10) → 取最高+10分

逻辑：先检查是否满足最高奖励条件，依次向下检查。

选项3：累积奖励原则

解释：满足多个条件时，分数累加。

计算方式：0.03M tokens → 0分(小于0.8M) +1分(小于0.5M) +3分(<0.1M) +5分(<0.05M) +10分(<0.01M) = 19分

注意：这种方式可能导致分数异常高，可能不是用户本意。
